VKomado 1.2.1 — 仮想ディスプレイビューア（Windows 11 x64）

旧名SharedVDの後継です。旧版を終了してからVKomado.exeを起動してください。
既存のキー設定を引き継ぐため、内部の設定・ログ保存先はSharedVDのまま維持します。

起動
VKomado.exe をダブルクリックしてください。管理者権限や開発ツールは不要です。
このポータブル版にはドライバーを同梱していません。Virtual Display Driverを別途導入し、
「VDD by MTT」1台を60Hzの拡張ディスプレイとして有効にしてください。
ドライバーの導入・ON／OFFも管理する場合はセットアップ版を利用してください。

ショートカット設定
「表示 → ショートカット設定」で、帰還・一覧・直接移動のキーを変更・無効化できます。
設定はユーザー別に保存し、次回起動に復元します。初期値はF6／Shift+F6／F8です。
他アプリのグローバル登録との競合は検出しますが、Adobe・IDE等のアプリ内キーとの重複は自動判定できません。
設定だけを開くには VKomado.exe --shortcuts を実行します。
以下のキー表記は初期値です。変更した場合は設定したキーを使ってください。

操作
・映像をクリックすると、ボタンを離した時点で仮想画面の該当位置へカーソルが移ります。
  移動先のクリックは送信しません。移動後は通常のマルチディスプレイと同様に操作できます。
・F6でメイン画面中央へ戻り、位置を示すリングを表示します。
・F8でアクティブウィンドウを往復移動します。仮想画面上ならメインへ、それ以外なら仮想画面へ。
  移動方向はカーソルではなくウィンドウの位置で決まります。最大化と付属ダイアログにも対応します。
・「ショートカット設定」の「新しい付属ダイアログを仮想画面の親へ寄せる」を有効にすると、
  新しい同一プロセスの付属ダイアログを一度だけ移動します（試験的・初期値OFF）。
  既存のウィンドウや独立した新規アプリは対象外。カーソル・フォーカスは変更しません。
  共有中は移動したダイアログの内容も共有されます。
・Shift+F6でサムネイル一覧を表示します。全画面の対象ウィンドウを、
  「仮想画面へ送る」「メイン画面へ戻す」の2つの一覧から選べます。
  カーソル位置で最初の一覧を選択し、上部のボタン／Ctrl+Tabで反対側へ切り替えられます。
  両側の件数を表示し、選択中の側は水色になります。F6でカーソルを戻す必要はありません。
  クリック、矢印＋Enterで移動。Escまたは同じキーでもう一度押すと取り消します。
  6件を超える場合は前へ／次へ、ホイール、PageUp／PageDownで切り替えます。
  最大化は維持、最小化は復元。表示中の付属ダイアログも一緒に移動します。
  同じアプリの独立した別ウィンドウは移しません。
・帰還・選択キーはビューア起動中、別アプリにフォーカスがあっても動作します。
  登録できない場合は表示メニューから操作するか、ショートカット設定を変更してください。
・通常は枠なし。マウスを乗せるとタイトルバーが現れます。
  タイトル部分で移動、端・角でリサイズ、「表示」で倍率を変更できます。
  縦横比を維持し、実際の倍率をタイトルに表示します。
・ビューアにフォーカスがあるとき、F11で全画面、Escで全画面を終了します。
・×／Alt+F4で終了する前に、仮想画面のアプリをメイン画面へ通常表示で戻します。
  退避できないウィンドウがある場合は警告し、終了を中止します。
  「表示 → 仮想画面のウィンドウをメイン画面へ戻す」でも一括退避できます。
  アプリの終了・内容の保存は行いません。VDD自体は有効のまま残ります。
・画面共有ではビューアのウィンドウではなく、仮想モニター全体を選んでください。

制限と診断
対象VDDは1台です。管理者権限や独自配置処理を持つアプリは移動できない場合があります。
非表示・別のWindows仮想デスクトップのウィンドウは退避対象外です。
クラッシュや強制終了では自動退避できません。別プロセスや親の不明なダイアログは自動追従しません。
1.1で保存したキー設定は旧1.0では読めないため、旧版へ戻す場合はキーの再設定が必要です。
各会議アプリでの共有、異なるDPIの組み合わせ、長時間動作は幅広い環境での追加検証が必要です。
ログは %LOCALAPPDATA%\SharedVD\Logs に保存します。映像は保存しません。

削除
ビューアを終了して、このフォルダーを削除してください。
ログ・ショートカット設定も不要なら %LOCALAPPDATA%\SharedVD を削除できます。
VDDの削除は別工程です。このEXEはドライバーの追加・削除を行いません。

開発者向け起動オプション
--monitor-match "VDD by MTT" --require-refresh-hz 60 --log "C:\path\viewer.log"
--fullscreen / --auto-exit-ms 10000
--rescue-windows : ビューアを開かず、対象仮想画面のウィンドウをメインへ戻して終了
--list-windows : 退避対象をログへ列挙（移動しない）
--keep-windows : 診断用。終了時の自動退避を無効にする
