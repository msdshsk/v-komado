# VKomado

**画面の中に、もうひとつの作業スペース。**

[紹介サイト](https://msdshsk.github.io/v-komado/) · [ダウンロード / Releases](https://github.com/msdshsk/v-komado/releases/latest) · [不具合報告](https://github.com/msdshsk/v-komado/issues)

Windows 11の仮想ディスプレイを、手元の画面内のウィンドウとして表示・操作するツールです。物理画面を4Kのまま使い、会議共有用の1080p画面などを別に用意できます。

仮想ディスプレイには [Virtual Display Driver](https://github.com/VirtualDrivers/Virtual-Display-Driver)、ビューアの基盤には [Windows Virtual Monitor Loopback](https://github.com/giri256/windows-virtual-monitor-loopback) を利用しています。

## 動作環境

- Windows 11 x64、Direct3D 11／Windows Graphics Capture対応環境。
- 対象VDDは1台。物理画面をプライマリとして使用します。
- セットアップは管理者権限が必要。通常のビューア・ショートカット設定は管理者権限不要です。

## インストールと操作

[最新リリース](https://github.com/msdshsk/v-komado/releases/latest)からセットアップEXEをダウンロードしてください。VDD導入済みの環境にはビューア単体のポータブルZIPも用意しています。

`VKomado-1.2.0-Setup-win-x64.exe` を実行し、スタートメニューの「VKomado」を開きます。既存のVDDが1台ある場合は再利用し、アンインストール時もそのドライバーを残します。詳細は [セットアップと復旧](docs/SETUP.md) を参照してください。

旧名SharedVDからはアンインストールせず上書き更新できます。管理画面・ビューア・ショートカット設定を閉じてからセットアップを実行してください。既存のVDDとキー設定を引き継ぎます。互換性のため、インストール先・設定保存先など内部の `SharedVD` 名は維持しています。

| 操作 | 動作 |
| --- | --- |
| ビューアの映像をクリック | 仮想画面の該当位置へカーソルを移動 |
| F6（初期値） | メイン画面中央へカーソルを戻し、位置を円で表示 |
| Shift+F6（初期値） | サムネイルからウィンドウを選んで画面間を移動 |
| F8（初期値） | アクティブウィンドウを仮想画面／メイン画面へ往復移動 |
| 表示 → ショートカット設定 | 帰還・一覧・直接移動のキーを変更／無効化、ダイアログ追従を設定 |
| ホバー時のタイトルバー | 移動・倍率・最大化・最小化・終了 |
| F11（ビューアにフォーカスがあるとき） | 全画面表示の切り替え |
| 通常終了 | 仮想画面上のアプリをメイン画面へ退避 |

ウィンドウ選択では、全画面の対象ウィンドウを「仮想画面へ送る」「メイン画面へ戻す」の2つの一覧から選べます。カーソルが仮想画面内なら「戻す」、それ以外なら「送る」を最初に表示します。上部のボタンまたはパネル内のCtrl+Tabで一覧を切り替えられるので、F6でカーソルを戻す必要はありません。クリック／矢印＋Enterで選択、Escでキャンセルします。[詳しい操作](docs/WINDOW-PICKER.md)

ショートカットは管理画面からも変更でき、ユーザー別に保存されます。グローバル登録の競合は検出しますが、AdobeやIDEのアプリ内ショートカットとの重複は自動判定できません。[設定と制約](docs/SHORTCUTS.md)

F8の移動先はカーソル位置ではなくアクティブウィンドウの現在位置で決まります。仮想画面上ならメインへ、それ以外なら仮想画面へ移動します。独立した新規アプリや、親を特定できないダイアログもこのキーで移動できます。

**画面共有では、ビューアのウィンドウではなく仮想モニター全体を選んでください。** 仮想画面上に表示された別ウィンドウやダイアログも共有対象になります。「ショートカット設定」には、新しい付属ダイアログを仮想画面の親へ寄せる試験的な設定があります（初期値OFF）。[対象と制限](docs/WINDOW-PICKER.md#新しいダイアログの追従試験的)を確認して有効にしてください。

## 解像度

新規VDDの初期設定は1920×1080・60Hzです。Windowsのディスプレイ設定から720p／1080p／1440p／4Kを選べます。旧版からの更新では既存設定を維持するため、1080pしか出ない場合はインストール先の `Tools/Enable-ResolutionPresets.cmd` を使います。[反映手順](docs/RESOLUTION-PRESETS.md)

## ソースからビルド

Visual Studio 2022の「C++によるデスクトップ開発」、Windows SDK、CMakeを用意してください。セットアップのビルドにはPowerShell 7を使用します。ビルド済みアプリの利用に開発ツールや.NETの別途導入は不要です。

```powershell
# ビューアだけをビルド（VDDのダウンロード・導入は不要）
.\scripts\Build-Loopback.ps1

# ポータブル配布用EXEとZIP
.\scripts\Package-Viewer.ps1

# 固定バージョンの署名済みドライバーとポータブルInno Setupを取得
.\scripts\Prepare-BuildDependencies.ps1 -SetupTools

# 管理画面、補助EXE、セットアップをビルド
.\scripts\Build-Setup.ps1
```

出力は `artifacts/releases/`。依存物はSHA256・署名を検証します。準備スクリプトはVDDをインストールしません。Inno Setupの利用条件は [配布元](https://jrsoftware.org/isorder.php) を参照してください。

`viewer/` に改変済みビューアを同梱しているため、外部リポジトリの取得やパッチ適用は不要です。

## 検証

```powershell
# XML変更とファイル置換・復旧のテスト（実機の設定は変更しない）
powershell.exe -NoProfile -File .\tests\resolution_presets_tests.ps1

# 仮想画面が有効なPCでのビューア統合テスト
.\scripts\Test-Viewer.ps1
```

統合テストは既存ビューアを閉じた状態で実行してください。テスト自身のウィンドウとカーソルを操作します。現在の16:9解像度で実行し、ユーザーの解像度・ショートカット設定は変更しません。ドライバーの導入・削除はこのテストに含みません。CIではビューアのビルドとXMLテストを行います。

## 制限

- 解像度のアプリ内選択・次回ON時の維持は未対応。OFF→ONで1080pに戻る場合があります。
- 管理者権限のアプリや独自配置処理を持つアプリではウィンドウ移動に失敗する場合があります。
- 非表示ウィンドウや別のWindows仮想デスクトップ、クラッシュ・強制終了時の退避は対象外です。
- 別PCでの新規ドライバー導入、異なるDPIの組み合わせ、各会議アプリでの共有、長時間動作は幅広い環境での追加検証が必要です。
- 配布EXE自体は未署名です。同梱VDDは署名済みの配布物を改変せず使用します。
